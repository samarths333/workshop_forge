    Where Rivet's head comes from

    Primary is NVIDIA NIM over the network. If the key is missing, the model errors, or the request times out, it falls through to Ollama on this machine. If both are down, a built-in keyword planner keeps the shop running.

    NVIDIA NIM

    Free key at build.nvidia.com — developer program, no card. Rate limited around 40 requests/minute, which is far more than this app needs.

    Ollama (fallback)

    Pull one first: ollama pull llama3.2:3b. Ollama gets the JSON schema enforced at the decoder, so a 3B model is enough here.

    Reference designs

    Before planning, Rivet looks up how people actually make the thing you asked for. Real part names and proportions from published models, fed straight into the prompt — it is the cheapest way to stop him guessing.

    Free at thingiverse.com/developers/apps — create an app, copy the App Token. Everything on Thingiverse is openly licensed, which is why it goes first. Printables needs no token but its endpoint is undocumented, so it is treated as best-effort. Either way a failed lookup never blocks a build.
