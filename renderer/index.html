      Where the floor's head comes from

      Nine engines, and anything that speaks the OpenAI protocol. Add a key to as many as you like, drag nothing — the shop tries them in the order below and moves on the moment one will not answer. With no key at all it still builds, offline, from what it already knows.

      Engines

      A key is stored on this machine and never leaves it except to go to the provider it belongs to. Tick an engine to put it in the chain; the order of the chain is the order they are ticked in, top to bottom.

      Which engine does which job

      A build is not one call. The floor manager writes the work order and the inspector checks the result — two calls that want real reasoning. The five specialists answer small, tightly-schema'd briefs, all at once — five calls that want speed and not much else. Point them at different engines and you get a better object for less.

      Leave a job unset and it falls up to the next one that is set, so a single engine needs no wiring at all.

      Reference designs

      Before planning, the floor looks up how people actually make the thing you asked for. Real part names and proportions from published models, fed into the manager's work order and into every specialist's brief — it is the cheapest way to stop them guessing.

      A SearXNG instance — no key, no account, nothing to sign up for. Run your own and this is dependable: docker run -d -p 8888:8080 searxng/searxng, then put http://127.0.0.1:8888 above. Left blank it tries public instances and falls back to DuckDuckGo, which works until it doesn't — most public instances now ship with the JSON API off and sit behind bot checks. A failed lookup never blocks a build; press Test both to see which one is answering.

      Free at thingiverse.com/developers/apps — create an app, copy the App Token. Everything on Thingiverse is openly licensed, which is why it goes first. Printables needs no token but its endpoint is undocumented, so it is treated as best-effort. Either way a failed lookup never blocks a build.

      What he does with the shop to himself

      Left alone, the floor goes and finds something to build: the class it keeps getting wrong, the next thing on the ladder it has never made, a domain it has never touched. It stops the instant you type. What it teaches itself is capped below what you teach it, and a study build that falls over files its lessons and no recipe — otherwise a night of practice makes the library worse.

      Unattended study runs on the offline planner and what the floor already knows unless you tick the second box. Nobody wants to find their API key went overnight on a robot practising stools.
